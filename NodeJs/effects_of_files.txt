- .gitignore dùng để khi ta upload github lên thì các file hoặc thư mục ta đã ghi bên trong đó sẽ không upload lên
- viewEngine.js dùng để cấu hình các setting cho website
- route dùng để điều hướng các website
- public là các file ta sẽ công khai (chủ yếu dùng để sử dụng cho web VD: Hình ảnh, video,...)
- config là chỉnh cài đặt các cấu hình cho trang web
- views là chỉnh các file html
- .env là chỉnh các PORT đường dẫn cho localhost của chúng ta
- .sequelizerc cài setting môi trường cho mySQL
- connectDB.js là dữ liệu kết nối với database để nhằm kiểm tra xem nó đã kết nối với database chưa
- config.json trong file config nhằm chỉnh server database ta muốn chuyển tới
- models là các dữ liệu trên database
- CRUD là viết tắt của create, read, update, delete
- Services là các dịch vụ hay còn gọi đơn giản là các chức năng ta làm cho website
- Hash Password là nó sẽ băm các password của chúng ta thành các password khó đọc hơn (tăng tính bảo mật)

- Ngoài lề một chút là nếu nhìn các function quá nhiều ta muốn thu gọn là thì ấn tổ hợp phím (ctrl + k và ctrl + 0) và muốn mở ra lại thì (ctrl + k và ctrl + j)
