- Install npm
    - npm i express@4.17.1 ejs@3.1.5 body-parser@1.19.0 dotenv@8.2.0 (@ là cài theo version)
    - npm install @babel/core@7.12.10 --save-dev @babel/preset-env@7.12.10 --save-dev @babel/node@7.12.10 --save-dev nodemon@2.0.7 --save-dev
- Use MySQL
    - npm i sequelize-cli@6.2.0 --save-dev (cli viết tắt của command line interface)
    - npm i sequelize@6.6.2 --save
    - npm i mysql2@2.2.5 (Cài mySQL)
    - npx sequelize-cli init (Cài đặt các folder có trong .sequelizerc)
    - npx sequelize-cli model:generate --name User --attributes firstName:string,lastName:string,email:string (Tạo model hay còn gọi là tạo bảng)
    - npx sequelize-cli db:migrate (Tạo migrations hiểu đơn giản là upload nó lên)
    - npx sequelize-cli seed:generate --name demo-user (Tạo seed upload dữ liệu lên)
    - npx sequelize-cli db:seed:all (Running seed, update seed) (Bị lỗi thì đọc trong the_errors_i_got.txt)
- Bảo mật người dùng
    - npm i bcrypt@5.0.1
- Chia sẻ tài nguyên bị hạn chế trên một trang web
    - npm i cors@2.8.5
